# 屏幕拼贴 · 品牌故事 · 风格规范

## 1. 参考片
`33_screen-collage`（57.0s，1920×1080，2 个切点，24 帧抽检）

- 底色分布：暗底均值 0.926（0.684–1.0）、亮底均值 0.022
- 主色板：#000103 · #00050c · #020a15 · #060f1b · #0c1527 · #192136 · #263043 · #404657
- 最常见底色：#000000×23 / #001818×1
- 实测强调色：#181848×9 / #183048×3 / #f060a8×1
- 文字分带出现率：页眉 0.88 / 上部 0.71 / 中部 0.83 / 下部 0.75 / 底部 0.46

## 2. 画布与令牌
- 画布：1920×1080 / 30fps
- 底色：light `#eeeef7` → dark `#080a1c`
- 墨色：`#0d0e22` / `#f1f1fb`
- 唯一强调色：`#5b47e0`（暗底提亮 `#9c8cff`）
- 辅助灰：`#6c6c7b` / `#9899a6`
- 字体：Noto Sans SC（标题 69–99px）· 正文 Noto Sans SC · HUD/微标 GeistMono；缺字回落 Noto Sans SC，全部为本地 OFL 字体

## 3. 版面
- 版心：左右 0.062 画布短边
- 标题块顶 0.150 高、开场大字顶 0.200 高
- 内容区 0.340–0.818 高，其下留字幕安全区

## 4. 装饰语言
- 底纹：ruler
- 标题：plain；面板：window；项目符号：dot
- 圆角：0.012 画布短边

## 5. 节奏
- 入场：settle / inout，元素间隔 0.14s
- 主题交替：dark、light，默认 dark

## 6. 人物
- 默认样式：card；可用 card, small, none
- 竖卡 0.400×0.700（短边比），圆框直径 0.215
- 人物框几何与 `scripts/build_jianying_draft.py` 的 `FRAMES` 同源，`runtime.js` 与草稿不会错位

## 7. 本风格专属记号
深夜蓝底 + 紫粉双强调 + 窗口面板 + 底部刻度尺，产品发布片的镜头感
