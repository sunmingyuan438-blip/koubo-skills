# 色块几何 · 知识讲解 · 风格规范

## 1. 参考片
`44_color-geometry`（23.9s，1920×1080，0 个切点，24 帧抽检）

- 底色分布：暗底均值 0.049（0.002–0.071）、亮底均值 0.8
- 主色板：#171411 · #1b4b94 · #264a87 · #272627 · #725b50 · #a0856b · #b4a17e · #be3619
- 最常见底色：#d8d8c0×12 / #d8c0a8×12
- 实测强调色：#c03018×8 / #184890×8 / #d89018×4
- 文字分带出现率：页眉 1.0 / 上部 0.96 / 中部 0.92 / 下部 0.21 / 底部 0.96

## 2. 画布与令牌
- 画布：1920×1080 / 30fps
- 底色：light `#ede3c8` → dark `#1c1a17`
- 墨色：`#1a1714` / `#ede3c8`
- 唯一强调色：`#c0271f`（暗底提亮 `#e8493f`）
- 辅助灰：`#736d60` / `#9e9785`
- 字体：Noto Sans SC（标题 73–105px）· 正文 Noto Sans SC · HUD/微标 GeistMono；缺字回落 Noto Sans SC，全部为本地 OFL 字体

## 3. 版面
- 版心：左右 0.062 画布短边
- 标题块顶 0.150 高、开场大字顶 0.200 高
- 内容区 0.340–0.818 高，其下留字幕安全区

## 4. 装饰语言
- 底纹：frame
- 标题：boxed；面板：outline；项目符号：number
- 圆角：0.000 画布短边

## 5. 节奏
- 入场：settle / inout，元素间隔 0.2s
- 主题交替：light、dark，默认 light

## 6. 人物
- 默认样式：card；可用 card, small, none
- 竖卡 0.420×0.520（短边比），圆框直径 0.240
- 人物框几何与 `scripts/build_jianying_draft.py` 的 `FRAMES` 同源，`runtime.js` 与草稿不会错位

## 7. 本风格专属记号
古籍米黄 + 红蓝黄三原色 + 朱印式标题 + 双线边框，命题—证明的章法
