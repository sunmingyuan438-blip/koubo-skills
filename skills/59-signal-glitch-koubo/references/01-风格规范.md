# 信号故障 · 照片转场 · 风格规范

## 1. 参考片
`59_signal-glitch`（13.0s，1920×1080，1 个切点，13 帧抽检）

- 底色分布：暗底均值 0.85（0.092–1.0）、亮底均值 0.036
- 主色板：#000101 · #070a11 · #15151f · #222535 · #2c3246 · #3c3e51 · #4b526b · #595353
- 最常见底色：#000000×5 / #181830×3 / #787878×3
- 实测强调色：#183048×9 / #181848×8 / #304860×1
- 文字分带出现率：页眉 0.62 / 上部 0.0 / 中部 0.23 / 下部 0.15 / 底部 0.31

## 2. 画布与令牌
- 画布：1920×1080 / 30fps
- 底色：light `#e8ebf0` → dark `#0a0c13`
- 墨色：`#10131a` / `#f2f4f8`
- 唯一强调色：`#d21f55`（暗底提亮 `#ff3d6e`）
- 辅助灰：`#6b6e74` / `#9a9ca1`
- 字体：Noto Sans SC（标题 101–138px）· 正文 Noto Sans SC · HUD/微标 GeistMono；缺字回落 Noto Sans SC，全部为本地 OFL 字体

## 3. 版面
- 版心：左右 0.062 画布短边
- 标题块顶 0.150 高、开场大字顶 0.200 高
- 内容区 0.340–0.818 高，其下留字幕安全区

## 4. 装饰语言
- 底纹：scan
- 标题：tagged；面板：window；项目符号：arrow
- 圆角：0.000 画布短边

## 5. 节奏
- 入场：wipe / linear，元素间隔 0.08s
- 主题交替：dark、light，默认 dark

## 6. 人物
- 默认样式：card；可用 card, small, none
- 竖卡 0.400×0.700（短边比），圆框直径 0.215
- 人物框几何与 `scripts/build_jianying_draft.py` 的 `FRAMES` 同源，`runtime.js` 与草稿不会错位

## 7. 本风格专属记号
监视器近黑底 + 扫描线与青/品红错位条 + 取景角标，硬切快节奏
