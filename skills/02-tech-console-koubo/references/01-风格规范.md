# 控制台 · 横屏版 · 风格规范

## 1. 参考片
`02_tech-console`（129.8s，1920×1080，12 个切点，29 帧抽检）

- 底色分布：暗底均值 0.945（0.887–0.997）、亮底均值 0.002
- 主色板：#010101 · #020202 · #020304 · #030407 · #05090e · #0a0f15 · #0f161c · #172027
- 最常见底色：#000000×29
- 实测强调色：#183048×5 / #181848×3 / #303060×2
- 文字分带出现率：页眉 0.9 / 上部 0.83 / 中部 0.79 / 下部 0.31 / 底部 0.31

## 2. 画布与令牌
- 画布：1920×1080 / 30fps
- 底色：light `#f4f5f6` → dark `#05070a`
- 墨色：`#101418` / `#e8edf2`
- 唯一强调色：`#3f7fb8`（暗底提亮 `#5aa0dd`）
- 辅助灰：`#6b7783` / `#7d8b99`
- 字体：Noto Sans SC（标题 66–95px）· 正文 Noto Sans SC · HUD/微标 GeistMono；缺字回落 Noto Sans SC，全部为本地 OFL 字体

## 3. 版面
- 版心：左右 0.062 画布短边
- 标题块顶 0.150 高、开场大字顶 0.200 高
- 内容区 0.340–0.743 高，其下留字幕安全区

## 4. 装饰语言
- 底纹：hairline
- 标题：tagged；面板：window；项目符号：dash
- 圆角：0.008 画布短边

## 5. 节奏
- 入场：wipe / out3，元素间隔 0.14s
- 主题交替：dark、light，默认 dark

## 6. 人物
- 默认样式：card；可用 card, small, none
- 竖卡 0.430×0.726（短边比），圆框直径 0.207
- 人物框几何与 `scripts/build_jianying_draft.py` 的 `FRAMES` 同源，`runtime.js` 与草稿不会错位

## 7. 本风格专属记号
近黑底 + 等宽字 + 窗口面板 + 刻度环，系统日志感
