# 剪辑单格式（plan.json）

引擎只负责排版和合成：**选哪段、剪多长、字幕写什么，都写在剪辑单里**。先用 `scripts/scan.py` 盘点素材、看缩略图条，再逐段写剪辑单。

```json
{
  "name": "周六独居日记",
  "style": "../style.json",
  "clips": [
    {"src": "素材/IMG_0001.MOV", "in": 2.0, "out": 4.4, "stamp": "08:10", "text": "周六 不定闹钟"},
    {"src": "素材/IMG_0002.MOV", "in": 0.5, "out": 2.6, "text": "拉开窗帘 天晴了", "vol": 0.6}
  ],
  "vo": [{"clip": 1, "offset": 0.2, "text": "开在巷子口的小面馆。"}],
  "music": {"file": "我的配乐.mp3", "offset": 12.0, "volume": 0.7},
  "title": {"template": "place", "text": "海边小城", "en": "Seaside Town", "sub": "DAY 1"},
  "end": {"text": "下一站 见"},
  "overlays": [{"template": "opener", "text": "桌面好物开箱", "at": 0.05, "dur": 2.0}]
}
```

## clips（按播放顺序）

| 字段 | 说明 |
|---|---|
| `src` | 素材路径（相对剪辑单所在目录，或绝对路径）。视频或照片都行，照片用 `dur` 给时长 |
| `in` / `out` | 入点、出点（秒，素材内的时间）。出点不能超过素材长度 |
| `speed` | 变速，默认 1。0.5 慢放、2 快进；声音同步变速 |
| `vol` | 这一段原声的音量（0 静音，1 原样）。不写就用风格默认值 |
| `move` | 后期运镜：`push` 推近、`pull` 拉远、`pan_l`/`pan_r` 横移、`tilt_up`/`tilt_down`。手持素材通常不用加 |
| `fit` | 横拍素材放进竖屏：`cover` 裁满（默认）或 `blur` 模糊底 + 完整画面 |
| `transition` | 这一段**进入下一段**的转场：`cut`（默认）`fade` `white` `black` `dissolve` `zoom` `slide`；`transition_dur` 秒数 |
| `inset` / `tilt` | 白边相框（mini 片风格），`tilt` 是相框倾斜角度 |
| `bw` | 这一段转黑白 |
| 文字字段 | 每套风格不同，见该风格的 `references/风格规范.md`：如 `text` `stamp` `en` `hl` `tag` `price` `no` `name` `word` |
| `text_at` / `text_dur` | 字幕相对这一段开头的出现时间和时长（不写就整段显示） |

## 自动节奏（默认开启）

6 套风格都开了自动节奏（`style.json#pace.auto`）。这时 **clips 里的 `in` / `out` 是「可用区间」**，不是最终剪点；引擎会：

1. 按风格的节奏型（`pace.base` × `pace.pattern`）给每一刀分配时长，长短交替，隔几刀一个喘气长镜头；
2. 分析每段素材的画面运动和声音，在可用区间里挑**动作最饱满**的一截（喘气 / 特写挑最稳的一截），两端避开说话；
3. 素材够长时拆成 2–3 刀**跳切**（后几刀不重复字幕）；
4. 剪点对齐配乐节拍；
5. 字幕读不完时**跨到后面的镜头**继续显示（按字数算时长）；片头标题最晚在第一句字幕出现时收掉。

每段可以加的控制字段：

| 字段 | 作用 |
|---|---|
| `role` | `hook` 开头钩子（短）、`fast` 快闪（开头高光）、`breath` 喘气长镜头、`detail` 特写（挑稳的一截） |
| `len` | 指定这一刀的时长（秒），仍会卡拍 |
| `lock` | `true` 时完全按剪辑单的 in/out，不自动挑 |
| `split` / `no_split` | 最多拆几刀 / 不拆 |
| `steady` | 挑最稳的一截 |

不要自动节奏：剪辑单写 `"auto_pace": false`；只改参数：`"pace": {"base": 1.6}`。

## vo（旁白，可选）

- `clip` + `offset`：挂在第几段（从 0 数）开始后多少秒；或者用 `at` 写成片里的绝对时间。
- 没有 `file` 时用 Fish **公共音色**自动合成（`voice` 写在剪辑单顶层，默认用风格的音色；不用任何个人克隆音色）。
- 有自己录的旁白就给 `file`。
- 一句旁白可以跨好几段画面；如果它会撞上下一句旁白，引擎会把它覆盖的最后一段画面往后放（素材够长时），这就是「以音频为轴铺画面」。
- 风格带旁白字幕时，长句会按标点切成一屏一句；`no_caption: true` 不出字幕。
- 有旁白时配乐自动压低（侧链压缩）。

## 素材自带的口播（真人说话的原声）

把说话那段的 `vol` 设成 1，把要上屏的话写进这一段的 `text`；一句话跨段时用顶层 `overlays` 按时间放字幕。先用 `scan.py --asr` 拿到口播文字和时间轴，再挑要留的句子（吃播闲聊只保留有用的句子）。

## music

- `file`：配乐文件；`offset` 从配乐的第几秒开始；`volume`。
- 不写 `music` 时，引擎按风格合成一首**程序生成的原创配乐**（没有版权问题，但只适合打样；正式发布换成自己有授权的音乐）。`"no_music": true` 不要配乐。
- 风格开了卡点（`pace.snap`）时，引擎会把每个剪点挪到最近的节拍上（只改出点，不会超出素材长度）。剪辑单写 `"snap": false` 关掉。

## title / end / overlays

- `title`：片头文字（模板名见风格规范），`at`、`dur` 控制时间。
- `end`：片尾文字，压在最后一段上。
- `overlays`：任意时间的文字图层，`template` 必填，`at`/`dur` 或 `clip`/`offset`。
- 常驻角标（如 REC、MINI VLOG.）的变量放在 `badge_vals`，例：`{"date": "2026.11.26"}`。

## 其他顶层字段

`canvas`（`portrait`/`landscape`，覆盖风格默认）、`fps`、`max_short`（限制短边，例如 1080）、`short`（强制短边，素材是低清代理时用）、`force_sdr`、`style_overrides`（局部覆盖风格，如换字号）、`voice`、`voice_speed`、`fit_vo`。
