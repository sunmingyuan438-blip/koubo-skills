# 流程演示 · 产品教程 · 风格规范

## 1. 参考片
`37_workflow-demo`（58.8s，1920×1080，20 个切点，25 帧抽检）

- 底色分布：暗底均值 0.297（0.0–1.0）、亮底均值 0.531
- 主色板：#020303 · #0f0f12 · #17181d · #2b4481 · #2c49fb · #414438 · #4d6ce2 · #928c16
- 最常见底色：#f0f0d8×11 / #c0f030×5 / #000000×4
- 实测强调色：#1848f0×11 / #c0f030×8 / #181860×2
- 文字分带出现率：页眉 0.64 / 上部 0.68 / 中部 0.92 / 下部 0.48 / 底部 0.24

## 2. 画布与令牌
- 画布：1920×1080 / 30fps
- 底色：light `#f4f3ec` → dark `#17161b`
- 墨色：`#1a1a1e` / `#f6f5ef`
- 唯一强调色：`#e8432c`（暗底提亮 `#ff6b55`）
- 辅助灰：`#767575` / `#a1a09e`
- 字体：Noto Sans SC（标题 82–116px）· 正文 Noto Sans SC · HUD/微标 GeistMono；缺字回落 Noto Sans SC，全部为本地 OFL 字体

## 3. 版面
- 版心：左右 0.062 画布短边
- 标题块顶 0.150 高、开场大字顶 0.200 高
- 内容区 0.340–0.818 高，其下留字幕安全区

## 4. 装饰语言
- 底纹：none
- 标题：plain；面板：solid；项目符号：number
- 圆角：0.016 画布短边

## 5. 节奏
- 入场：rise / out3，元素间隔 0.12s
- 主题交替：light、dark，默认 light

## 6. 人物
- 默认样式：card；可用 card, small, none
- 竖卡 0.400×0.700（短边比），圆框直径 0.215
- 人物框几何与 `scripts/build_jianying_draft.py` 的 `FRAMES` 同源，`runtime.js` 与草稿不会错位

## 7. 本风格专属记号
奶白/炭黑/珊瑚红三张底轮换 + 对话气泡式面板，一步一屏的教程
