# 检查与踩坑

## 自检命令
```sh
node scripts/engine/render.mjs build examples/shots-控件演示.json examples/inst-demo
node scripts/engine/render.mjs audit examples/inst-demo --pretty
node scripts/engine/render.mjs preview examples/inst-demo examples/preview/t3.png --time 3
python3 ../../../style-build/tools/verify.py examples/preview/t3.png
```
`audit`（版面审计，按像素判定）：每个镜头取入场结束后的一帧，检查文字是否超出版心、溢出自身盒子或面板、进入字幕区、压到人物框、互相压字、字号低于下限（正文 ≥ 短边 1.45%，HUD/kicker ≥ 短边 1.2%）；有任何一项违规就 exit 1。字段上限（LIMITS）仍是第一道闸，audit 是第二道。
`verify.py` 输出：底色占比、主色分箱、强调色占比、OCR 文字框位置（y 为底边向上归一化）。

## 本风格的坑
- 画幅是 1080×1920：所有几何都按比例算，改画布不用改代码
- 强调色只有一个：`#0f5c46`，不要在 props 里写别的颜色
- 人物框宽高必须与 `FRAMES` 一致，改 `style.json` 后要重新生成草稿
- 字体必须本地：`stage/fonts/` 里只放 OFL 字体（Noto Sans SC、GeistMono，以及本条 style.json#type 指定的第二/三字族及其 OFL 许可文本）
- 竖屏人物改右上圆框：标题区会被圆框让位，title 超过 6 个字会缩字
- paper 底纹是横向细纹，导出 H.264 低码率时会出现摩尔纹，渲染码率不要低于 8 Mbps
