# 纸面观点 · 竖屏版 · 风格规范

## 1. 参考片
`08_paper-perspective-portrait`（260.9s，1080×1920，29 个切点，29 帧抽检）

- 底色分布：暗底均值 0.178（0.0–0.992）、亮底均值 0.774
- 主色板：#060909 · #09100c · #0a100d · #0c1310 · #0f1713 · #192822 · #62615b · #7f7e80
- 最常见底色：#d8d8d8×24 / #000000×5
- 实测强调色：#18c0a8×2 / #186048×1 / #18c090×1
- 文字分带出现率：页眉 0.97 / 上部 0.72 / 中部 0.69 / 下部 0.31 / 底部 0.0

## 2. 画布与令牌
- 画布：1080×1920 / 30fps
- 底色：light `#eeeee6` → dark `#0d1411`
- 墨色：`#14120e` / `#f2f0e6`
- 唯一强调色：`#0f5c46`（暗底提亮 `#18b89e`）
- 辅助灰：`#6f6d63` / `#a8a69a`
- 字体：Noto Sans SC（标题 73–105px）· 正文 Noto Sans SC · HUD/微标 GeistMono；缺字回落 Noto Sans SC，全部为本地 OFL 字体

## 3. 版面
- 版心：左右 0.068 画布短边
- 标题块顶 0.140 高、开场大字顶 0.250 高
- 内容区 0.300–0.670 高，其下留字幕安全区

## 4. 装饰语言
- 底纹：paper
- 标题：underline；面板：paper；项目符号：number
- 圆角：0.012 画布短边

## 5. 节奏
- 入场：settle / out3，元素间隔 0.16s
- 主题交替：light、dark，默认 light

## 6. 人物
- 默认样式：card；可用 card, small, none
- 竖卡 0.227×0.392（短边比），圆框直径 0.204
- 人物框几何与 `scripts/build_jianying_draft.py` 的 `FRAMES` 同源，`runtime.js` 与草稿不会错位

## 7. 本风格专属记号
米白纸底竖屏，人物改右上圆框
