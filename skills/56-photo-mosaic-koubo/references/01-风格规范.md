# 照片马赛克 · 画面揭晓 · 风格规范

## 1. 参考片
`56_photo-mosaic`（14.0s，1920×1080，0 个切点，14 帧抽检）

- 底色分布：暗底均值 0.85（0.192–1.0）、亮底均值 0.005
- 主色板：#062248 · #0b101a · #0e3973 · #1b58a2 · #2e1e17 · #31393e · #5074ab · #5a5759
- 最常见底色：#000000×4 / #000018×3 / #181818×2
- 实测强调色：#001848×6 / #481800×5 / #003078×4
- 文字分带出现率：页眉 0.36 / 上部 0.0 / 中部 0.0 / 下部 0.0 / 底部 0.29

## 2. 画布与令牌
- 画布：1920×1080 / 30fps
- 底色：light `#e9f0f8` → dark `#0b2548`
- 墨色：`#0f2440` / `#eef5ff`
- 唯一强调色：`#c4541a`（暗底提亮 `#ff9a52`）
- 辅助灰：`#6b7a8d` / `#98a6b9`
- 字体：Noto Sans SC（标题 69–99px）· 正文 Noto Sans SC · HUD/微标 GeistMono；缺字回落 Noto Sans SC，全部为本地 OFL 字体

## 3. 版面
- 版心：左右 0.062 画布短边
- 标题块顶 0.150 高、开场大字顶 0.200 高
- 内容区 0.340–0.818 高，其下留字幕安全区

## 4. 装饰语言
- 底纹：mosaic
- 标题：plain；面板：glass；项目符号：dot
- 圆角：0.008 画布短边

## 5. 节奏
- 入场：pop / out3，元素间隔 0.08s
- 主题交替：dark、light，默认 dark

## 6. 人物
- 默认样式：card；可用 card, small, none
- 竖卡 0.400×0.700（短边比），圆框直径 0.215
- 人物框几何与 `scripts/build_jianying_draft.py` 的 `FRAMES` 同源，`runtime.js` 与草稿不会错位

## 7. 本风格专属记号
深海蓝底 + 四周密、中间疏的小方格 + 橙色点睛，由碎片拼出答案
