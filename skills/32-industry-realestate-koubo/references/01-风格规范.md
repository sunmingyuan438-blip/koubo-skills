# 房产 · 一镜带看 · 风格规范

## 1. 参考片
`32_industry-realestate`（108.5s，1080×1920，1 个切点，28 帧抽检）

- 底色分布：暗底均值 0.866（0.527–0.97）、亮底均值 0.034
- 主色板：#0a1019 · #0d131e · #0e1521 · #131925 · #222631 · #333438 · #494746 · #615c58
- 最常见底色：#000018×25 / #000000×3
- 实测强调色：#181848×3 / #4878f0×2 / #f09030×2
- 文字分带出现率：页眉 0.96 / 上部 0.89 / 中部 0.82 / 下部 0.96 / 底部 1.0

## 2. 画布与令牌
- 画布：1080×1920 / 30fps
- 底色：light `#eef1f6` → dark `#04060d`
- 墨色：`#0c1018` / `#e9eefb`
- 唯一强调色：`#5f8fdd`（暗底提亮 `#7ea6f0`）
- 辅助灰：`#5f6878` / `#8e99ad`
- 字体：Noto Sans SC（标题 69–99px）· 正文 Noto Sans SC · HUD/微标 GeistMono；缺字回落 Noto Sans SC，全部为本地 OFL 字体

## 3. 版面
- 版心：左右 0.068 画布短边
- 标题块顶 0.140 高、开场大字顶 0.250 高
- 内容区 0.300–0.690 高，其下留字幕安全区

## 4. 装饰语言
- 底纹：gradient
- 标题：plain；面板：glass；项目符号：number
- 圆角：0.020 画布短边

## 5. 节奏
- 入场：flip / inout，元素间隔 0.18s
- 主题交替：dark、light，默认 dark

## 6. 人物
- 默认样式：small；可用 card, small, none
- 竖卡 0.183×0.293（短边比），圆框直径 0.184
- 人物框几何与 `scripts/build_jianying_draft.py` 的 `FRAMES` 同源，`runtime.js` 与草稿不会错位

## 7. 本风格专属记号
房产类：夜蓝渐变 + 天蓝，一镜动线（步骤）为主轴
