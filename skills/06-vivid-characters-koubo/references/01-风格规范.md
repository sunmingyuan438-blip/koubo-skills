# 鲜活角色 · 竖屏版 · 风格规范

## 1. 参考片
`06_vivid-characters`（121.9s，1080×1920，11 个切点，28 帧抽检）

- 底色分布：暗底均值 0.353（0.005–1.0）、亮底均值 0.333
- 主色板：#000000 · #040404 · #0a0605 · #251c17 · #4a58f1 · #5666e6 · #674d4d · #9e624e
- 最常见底色：#000000×10 / #f0f0f0×7 / #d8d8f0×3
- 实测强调色：#f0c018×4 / #6048f0×3 / #1860d8×2
- 文字分带出现率：页眉 0.96 / 上部 0.89 / 中部 0.5 / 下部 0.39 / 底部 0.39

## 2. 画布与令牌
- 画布：1080×1920 / 30fps
- 底色：light `#f4efe6` → dark `#141018`
- 墨色：`#1a1620` / `#f7f1e8`
- 唯一强调色：`#f0a23c`（暗底提亮 `#ffbe63`）
- 辅助灰：`#6f6878` / `#a79fb0`
- 字体：Noto Sans SC（标题 86–116px）· 正文 Noto Sans SC · HUD/微标 GeistMono；缺字回落 Noto Sans SC，全部为本地 OFL 字体

## 3. 版面
- 版心：左右 0.068 画布短边
- 标题块顶 0.140 高、开场大字顶 0.250 高
- 内容区 0.300–0.780 高，其下留字幕安全区

## 4. 装饰语言
- 底纹：dot
- 标题：boxed；面板：glass；项目符号：check
- 圆角：0.020 画布短边

## 5. 节奏
- 入场：flip / inout，元素间隔 0.18s
- 主题交替：dark、light，默认 light

## 6. 人物
- 默认样式：card；可用 card, small, split, none
- 竖卡 0.177×0.265（短边比），圆框直径 0.289
- 人物框几何与 `scripts/build_jianying_draft.py` 的 `FRAMES` 同源，`runtime.js` 与草稿不会错位

## 7. 本风格专属记号
深色舞台 + 琥珀强调 + 点阵背景
