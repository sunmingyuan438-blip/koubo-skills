# 黏土实验室 · 知识讲解 · 风格规范

## 1. 参考片
`52_clay-lab`（207.0s，1920×1080，0 个切点，25 帧抽检）

- 底色分布：暗底均值 0.002（0.002–0.002）、亮底均值 0.886
- 主色板：#484543 · #79675a · #937f6c · #989a99 · #b3b3ae · #b99360 · #c9c9c2 · #cdad7a
- 最常见底色：#f0d8c0×24 / #d8c0c0×1
- 实测强调色：#d8a848×11 / #c09030×10 / #c09048×1
- 文字分带出现率：页眉 1.0 / 上部 0.68 / 中部 0.08 / 下部 0.36 / 底部 0.88

## 2. 画布与令牌
- 画布：1920×1080 / 30fps
- 底色：light `#f6ddd0` → dark `#2e2220`
- 墨色：`#3b2a26` / `#f9e6da`
- 唯一强调色：`#a8601a`（暗底提亮 `#f0b25a`）
- 辅助灰：`#8a756d` / `#ac9c93`
- 字体：Noto Sans SC（标题 86–116px）· 正文 Noto Sans SC · HUD/微标 GeistMono；缺字回落 Noto Sans SC，全部为本地 OFL 字体

## 3. 版面
- 版心：左右 0.062 画布短边
- 标题块顶 0.150 高、开场大字顶 0.200 高
- 内容区 0.340–0.818 高，其下留字幕安全区

## 4. 装饰语言
- 底纹：clay
- 标题：boxed；面板：glass；项目符号：dot
- 圆角：0.040 画布短边

## 5. 节奏
- 入场：pop / inout，元素间隔 0.2s
- 主题交替：light、dark，默认 light

## 6. 人物
- 默认样式：small；可用 card, small, none
- 竖卡 0.380×0.660（短边比），圆框直径 0.260
- 人物框几何与 `scripts/build_jianying_draft.py` 的 `FRAMES` 同源，`runtime.js` 与草稿不会错位

## 7. 本风格专属记号
