# 地铁线网 · 知识讲解 · 风格规范

## 1. 参考片
`51_metro-network`（193.4s，1920×1080，1 个切点，24 帧抽检）

- 底色分布：暗底均值 0.119（0.105–0.419）、亮底均值 0.805
- 主色板：#121316 · #17191b · #22282c · #333839 · #464b4e · #6a6362 · #6b8c85 · #937d79
- 最常见底色：#f0d8d8×24
- 实测强调色：#489078×4 / #309078×3
- 文字分带出现率：页眉 1.0 / 上部 1.0 / 中部 1.0 / 下部 1.0 / 底部 0.96

## 2. 画布与令牌
- 画布：1920×1080 / 30fps
- 底色：light `#f1efe8` → dark `#121315`
- 墨色：`#1c1c1c` / `#f1efe8`
- 唯一强调色：`#c8102e`（暗底提亮 `#ff4d63`）
- 辅助灰：`#757572` / `#9c9b98`
- 字体：Noto Sans SC（标题 66–95px）· 正文 Noto Sans SC · HUD/微标 GeistMono；缺字回落 Noto Sans SC，全部为本地 OFL 字体

## 3. 版面
- 版心：左右 0.062 画布短边
- 标题块顶 0.150 高、开场大字顶 0.200 高
- 内容区 0.340–0.818 高，其下留字幕安全区

## 4. 装饰语言
- 底纹：metro
- 标题：tagged；面板：solid；项目符号：number
- 圆角：0.006 画布短边

## 5. 节奏
- 入场：wipe / out3，元素间隔 0.12s
- 主题交替：light、dark，默认 light

## 6. 人物
- 默认样式：card；可用 card, small, none
- 竖卡 0.340×0.760（短边比），圆框直径 0.200
- 人物框几何与 `scripts/build_jianying_draft.py` 的 `FRAMES` 同源，`runtime.js` 与草稿不会错位

## 7. 本风格专属记号
米白底 + 红蓝绿三条线路与换乘站点 + 站牌式标签，按站推进
