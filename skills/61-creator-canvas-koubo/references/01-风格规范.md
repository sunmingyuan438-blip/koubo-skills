# 自由画布 · 协作叙事 · 风格规范

## 1. 参考片
`61_creator-canvas`（190.0s，1080×1920，8 个切点，25 帧抽检）

- 底色分布：暗底均值 0.206（0.001–0.947）、亮底均值 0.592
- 主色板：#0d0d0d · #161617 · #2e67e9 · #2f2d2e · #474a62 · #5b463d · #67769e · #956e62
- 最常见底色：#f0f0f0×17 / #000000×6 / #1860d8×1
- 实测强调色：#f04818×4 / #1860d8×2 / #f04830×2
- 文字分带出现率：页眉 1.0 / 上部 0.92 / 中部 1.0 / 下部 0.88 / 底部 1.0

## 2. 画布与令牌
- 画布：1080×1920 / 30fps
- 底色：light `#f6f6f4` → dark `#121317`
- 墨色：`#16171b` / `#f1f2f5`
- 唯一强调色：`#2e67e9`（暗底提亮 `#6b95ff`）
- 辅助灰：`#747576` / `#9c9da1`
- 字体：Noto Sans SC（标题 81–112px）· 正文 Noto Sans SC · HUD/微标 GeistMono；缺字回落 Noto Sans SC，全部为本地 OFL 字体

## 3. 版面
- 版心：左右 0.068 画布短边
- 标题块顶 0.140 高、开场大字顶 0.250 高
- 内容区 0.300–0.820 高，其下留字幕安全区

## 4. 装饰语言
- 底纹：canvasui
- 标题：tagged；面板：paper；项目符号：check
- 圆角：0.020 画布短边

## 5. 节奏
- 入场：pop / out3，元素间隔 0.12s
- 主题交替：light、dark，默认 light

## 6. 人物
- 默认样式：small；可用 card, small, none
- 竖卡 0.440×0.500（短边比），圆框直径 0.270
- 人物框几何与 `scripts/build_jianying_draft.py` 的 `FRAMES` 同源，`runtime.js` 与草稿不会错位

## 7. 本风格专属记号
在线画布界面：点阵白底 + 顶栏协作头像 + 左侧工具栏 + 底部波形播放条，内容是贴在画布上的白卡，蓝色主操作 + 红色关键词
