# 镜像万花筒 · 照片律动 · 风格规范

## 1. 参考片
`60_mirror-kaleidoscope`（13.0s，1920×1080，0 个切点，13 帧抽检）

- 底色分布：暗底均值 0.203（0.0–1.0）、亮底均值 0.091
- 主色板：#251b18 · #292c23 · #2e392a · #3e4732 · #456140 · #527b58 · #725556 · #819087
- 最常见底色：#304830×3 / #183018×3 / #a8a8a8×2
- 实测强调色：#f06030×2 / #c07830×1 / #781818×1
- 文字分带出现率：页眉 0.31 / 上部 0.0 / 中部 0.23 / 下部 0.0 / 底部 0.08

## 2. 画布与令牌
- 画布：1920×1080 / 30fps
- 底色：light `#f3f1ec` → dark `#12180f`
- 墨色：`#1f1a17` / `#f4f1ea`
- 唯一强调色：`#b53a26`（暗底提亮 `#ff8a5c`）
- 辅助灰：`#787470` / `#9e9f97`
- 字体：Noto Sans SC（标题 86–116px）· 正文 Noto Sans SC · HUD/微标 GeistMono；缺字回落 Noto Sans SC，全部为本地 OFL 字体

## 3. 版面
- 版心：左右 0.062 画布短边
- 标题块顶 0.150 高、开场大字顶 0.200 高
- 内容区 0.340–0.818 高，其下留字幕安全区

## 4. 装饰语言
- 底纹：kaleido
- 标题：plain；面板：glass；项目符号：dot
- 圆角：0.030 画布短边

## 5. 节奏
- 入场：flip / inout，元素间隔 0.16s
- 主题交替：light、dark，默认 light

## 6. 人物
- 默认样式：small；可用 card, small, none
- 竖卡 0.380×0.660（短边比），圆框直径 0.260
- 人物框几何与 `scripts/build_jianying_draft.py` 的 `FRAMES` 同源，`runtime.js` 与草稿不会错位

## 7. 本风格专属记号
十二瓣对称花纹从画面中心铺开（红/绿/橙）+ 圆润毛玻璃面板
