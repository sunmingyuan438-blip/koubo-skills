# 瑞士网格 · 知识讲解 · 风格规范

## 1. 参考片
`43_swiss-grid`（192.3s，1920×1080，0 个切点，25 帧抽检）

- 底色分布：暗底均值 0.001（0.0–0.004）、亮底均值 0.948
- 主色板：#2b3135 · #4b4d4e · #706261 · #7e7c7a · #969797 · #ab8f8b · #c7ada9 · #ca4d43
- 最常见底色：#d8d8d8×25
- 实测强调色：#d84830×5 / #d84848×4 / #d83030×2
- 文字分带出现率：页眉 1.0 / 上部 0.92 / 中部 0.48 / 下部 0.44 / 底部 0.76

## 2. 画布与令牌
- 画布：1920×1080 / 30fps
- 底色：light `#efeeea` → dark `#121212`
- 墨色：`#111111` / `#f0efeb`
- 唯一强调色：`#d6252b`（暗底提亮 `#ff5a5f`）
- 辅助灰：`#6e6e6c` / `#9c9b99`
- 字体：Noto Sans SC（标题 75–127px）· 正文 Noto Sans SC · HUD/微标 GeistMono；缺字回落 Noto Sans SC，全部为本地 OFL 字体

## 3. 版面
- 版心：左右 0.062 画布短边
- 标题块顶 0.150 高、开场大字顶 0.200 高
- 内容区 0.340–0.818 高，其下留字幕安全区

## 4. 装饰语言
- 底纹：swiss
- 标题：plain；面板：solid；项目符号：number
- 圆角：0.000 画布短边

## 5. 节奏
- 入场：rise / out3，元素间隔 0.12s
- 主题交替：light、dark，默认 light

## 6. 人物
- 默认样式：card；可用 card, small, none
- 竖卡 0.420×0.520（短边比），圆框直径 0.240
- 人物框几何与 `scripts/build_jianying_draft.py` 的 `FRAMES` 同源，`runtime.js` 与草稿不会错位

## 7. 本风格专属记号
灰白底 + 十二栏参考线 + 粗黑顶线 + 单一红色，数字与比例说话
