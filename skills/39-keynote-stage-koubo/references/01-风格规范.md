# 发布会舞台 · 产品演示 · 风格规范

## 1. 参考片
`39_keynote-stage`（108.0s，1920×1080，6 个切点，24 帧抽检）

- 底色分布：暗底均值 0.222（0.0–1.0）、亮底均值 0.632
- 主色板：#000204 · #0a0c13 · #13151f · #2c313a · #4c4c61 · #626ace · #678098 · #797377
- 最常见底色：#f0f0f0×11 / #d8d8d8×4 / #000000×3
- 实测强调色：#183048×3 / #487890×1 / #4878a8×1
- 文字分带出现率：页眉 0.29 / 上部 0.5 / 中部 0.79 / 下部 0.29 / 底部 0.17

## 2. 画布与令牌
- 画布：1920×1080 / 30fps
- 底色：light `#f3f2ee` → dark `#0f0f14`
- 墨色：`#1b1b20` / `#f4f3f8`
- 唯一强调色：`#6a55f5`（暗底提亮 `#9d8cff`）
- 辅助灰：`#767577` / `#9d9ca1`
- 字体：Noto Sans SC（标题 90–127px）· 正文 Noto Sans SC · HUD/微标 GeistMono；缺字回落 Noto Sans SC，全部为本地 OFL 字体

## 3. 版面
- 版心：左右 0.062 画布短边
- 标题块顶 0.150 高、开场大字顶 0.200 高
- 内容区 0.340–0.818 高，其下留字幕安全区

## 4. 装饰语言
- 底纹：gradient
- 标题：plain；面板：paper；项目符号：dot
- 圆角：0.022 画布短边

## 5. 节奏
- 入场：settle / inout，元素间隔 0.22s
- 主题交替：light、dark，默认 light

## 6. 人物
- 默认样式：card；可用 card, small, none
- 竖卡 0.460×0.560（短边比），圆框直径 0.230
- 人物框几何与 `scripts/build_jianying_draft.py` 的 `FRAMES` 同源，`runtime.js` 与草稿不会错位

## 7. 本风格专属记号
暖白舞台 + 大号发布会标题 + 悬浮屏幕卡，「One more thing」式揭晓
