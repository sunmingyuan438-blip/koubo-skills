# 发光灯板 · 知识讲解 · 风格规范

## 1. 参考片
`45_glowing-lightboard`（210.3s，1920×1080，0 个切点，24 帧抽检）

- 底色分布：暗底均值 0.905（0.858–0.946）、亮底均值 0.002
- 主色板：#010407 · #020809 · #030a0d · #070e12 · #0b1319 · #101920 · #151e27 · #1c2731
- 最常见底色：#000000×24
- 实测强调色：#183048×11 / #304860×1 / #184848×1
- 文字分带出现率：页眉 1.0 / 上部 0.42 / 中部 0.62 / 下部 0.79 / 底部 0.96

## 2. 画布与令牌
- 画布：1920×1080 / 30fps
- 底色：light `#eaf3f4` → dark `#0b171e`
- 墨色：`#0f2a30` / `#e6f6f7`
- 唯一强调色：`#0b7f8c`（暗底提亮 `#5fe3e8`）
- 辅助灰：`#6b7e82` / `#93a1a5`
- 字体：Noto Sans SC（标题 69–99px）· 正文 Noto Sans SC · HUD/微标 GeistMono；缺字回落 Noto Sans SC，全部为本地 OFL 字体

## 3. 版面
- 版心：左右 0.062 画布短边
- 标题块顶 0.150 高、开场大字顶 0.200 高
- 内容区 0.340–0.818 高，其下留字幕安全区

## 4. 装饰语言
- 底纹：neon
- 标题：plain；面板：neon；项目符号：dash
- 圆角：0.006 画布短边

## 5. 节奏
- 入场：rise / inout，元素间隔 0.18s
- 主题交替：dark、light，默认 dark

## 6. 人物
- 默认样式：card；可用 card, small, none
- 竖卡 0.400×0.700（短边比），圆框直径 0.215
- 人物框几何与 `scripts/build_jianying_draft.py` 的 `FRAMES` 同源，`runtime.js` 与草稿不会错位

## 7. 本风格专属记号
玻璃灯板的近黑底 + 青/粉/黄霓虹波形 + 发光描边面板
