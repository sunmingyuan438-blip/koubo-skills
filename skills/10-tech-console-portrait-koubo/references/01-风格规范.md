# 控制台 · 竖屏版 · 风格规范

## 1. 参考片
`10_tech-console-portrait`（129.8s，1080×1920，13 个切点，29 帧抽检）

- 底色分布：暗底均值 0.964（0.94–0.993）、亮底均值 0.002
- 主色板：#010203 · #020405 · #030509 · #040910 · #050d17 · #07111b · #0c1622 · #121e2b
- 最常见底色：#000000×28 / #181830×1
- 实测强调色：#183048×6
- 文字分带出现率：页眉 0.9 / 上部 0.93 / 中部 0.76 / 下部 0.45 / 底部 0.0

## 2. 画布与令牌
- 画布：1080×1920 / 30fps
- 底色：light `#f4f5f6` → dark `#07090c`
- 墨色：`#101418` / `#e8edf2`
- 唯一强调色：`#3f7fb8`（暗底提亮 `#5aa0dd`）
- 辅助灰：`#6b7783` / `#7d8b99`
- 字体：Noto Sans SC（标题 66–95px）· 正文 Noto Sans SC · HUD/微标 GeistMono；缺字回落 Noto Sans SC，全部为本地 OFL 字体

## 3. 版面
- 版心：左右 0.068 画布短边
- 标题块顶 0.140 高、开场大字顶 0.250 高
- 内容区 0.300–0.750 高，其下留字幕安全区

## 4. 装饰语言
- 底纹：hairline
- 标题：tagged；面板：window；项目符号：dash
- 圆角：0.008 画布短边

## 5. 节奏
- 入场：wipe / out3，元素间隔 0.14s
- 主题交替：dark、light，默认 dark

## 6. 人物
- 默认样式：small；可用 card, small, none
- 竖卡 0.208×0.333（短边比），圆框直径 0.208
- 人物框几何与 `scripts/build_jianying_draft.py` 的 `FRAMES` 同源，`runtime.js` 与草稿不会错位
