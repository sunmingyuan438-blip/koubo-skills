# 叠层剪纸 · 知识讲解 · 风格规范

## 1. 参考片
`50_layered-papercut`（198.8s，1920×1080，1 个切点，24 帧抽检）

- 底色分布：暗底均值 0.8（0.195–0.603）、亮底均值 0.016
- 主色板：#122c40 · #16354e · #173750 · #193951 · #2b4756 · #325061 · #465861 · #715640
- 最常见底色：#003048×20 / #a89060×3 / #184860×1
- 实测强调色：#003048×23 / #183048×11 / #184860×7
- 文字分带出现率：页眉 1.0 / 上部 0.12 / 中部 0.33 / 下部 0.25 / 底部 0.79

## 2. 画布与令牌
- 画布：1920×1080 / 30fps
- 底色：light `#f1e9d6` → dark `#1e4a5c`
- 墨色：`#1e3f4c` / `#f6f0df`
- 唯一强调色：`#1e5a6e`（暗底提亮 `#cfe07a`）
- 辅助灰：`#778686` / `#a4b1ad`
- 字体：Noto Sans SC（标题 73–105px）· 正文 Noto Sans SC · HUD/微标 GeistMono；缺字回落 Noto Sans SC，全部为本地 OFL 字体

## 3. 版面
- 版心：左右 0.062 画布短边
- 标题块顶 0.150 高、开场大字顶 0.200 高
- 内容区 0.340–0.818 高，其下留字幕安全区

## 4. 装饰语言
- 底纹：papercut
- 标题：boxed；面板：paper；项目符号：dot
- 圆角：0.012 画布短边

## 5. 节奏
- 入场：rise / inout，元素间隔 0.2s
- 主题交替：dark、light，默认 dark

## 6. 人物
- 默认样式：card；可用 card, small, none
- 竖卡 0.380×0.660（短边比），圆框直径 0.260
- 人物框几何与 `scripts/build_jianying_draft.py` 的 `FRAMES` 同源，`runtime.js` 与草稿不会错位

## 7. 本风格专属记号
深青底 + 四层带投影的纸片弧 + 土黄/草绿地层色 + 纸条式标题
