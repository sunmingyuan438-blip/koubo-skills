# 点阵笔记 · 知识讲解 · 风格规范

## 1. 参考片
`41_dot-grid-notes`（19.9s，1920×1080，0 个切点，20 帧抽检）

- 底色分布：暗底均值 0.026（0.002–0.2）、亮底均值 0.914
- 主色板：#29303b · #303644 · #363b45 · #505657 · #6c706f · #848886 · #989b97 · #aaaea7
- 最常见底色：#f0d8d8×20
- 实测强调色：#183048×3
- 文字分带出现率：页眉 1.0 / 上部 0.8 / 中部 0.85 / 下部 0.25 / 底部 0.95

## 2. 画布与令牌
- 画布：1920×1080 / 30fps
- 底色：light `#f2edde` → dark `#232c33`
- 墨色：`#26272c` / `#f2edde`
- 唯一强调色：`#2f8a66`（暗底提亮 `#8fdcbc`）
- 辅助灰：`#7c7a77` / `#a3a49d`
- 字体：站酷快乐体 ZCOOL KuaiLe（标题 90–120px）· 正文 Noto Sans SC · HUD/微标 GeistMono；缺字回落 Noto Sans SC，全部为本地 OFL 字体

## 3. 版面
- 版心：左右 0.062 画布短边
- 标题块顶 0.150 高、开场大字顶 0.200 高
- 内容区 0.340–0.818 高，其下留字幕安全区

## 4. 装饰语言
- 底纹：notes
- 标题：underline；面板：sticker；项目符号：number
- 圆角：0.008 画布短边

## 5. 节奏
- 入场：pop / inout，元素间隔 0.2s
- 主题交替：light、dark，默认 light

## 6. 人物
- 默认样式：small；可用 card, small, none
- 竖卡 0.380×0.660（短边比），圆框直径 0.260
- 人物框几何与 `scripts/build_jianying_draft.py` 的 `FRAMES` 同源，`runtime.js` 与草稿不会错位

## 7. 本风格专属记号
米色点阵本 + 手写感标题 + 薄荷/黄色和纸胶带 + 便利贴面板
