# 生长导图 · 知识讲解 · 风格规范

## 1. 参考片
`46_growing-mind-map`（214.1s，1920×1080，0 个切点，25 帧抽检）

- 底色分布：暗底均值 0.002（0.002–0.002）、亮底均值 0.901
- 主色板：#2f3639 · #4d5255 · #6b6e6c · #6c858c · #88948a · #a1aeac · #b7ac8c · #b7cbca
- 最常见底色：#d8d8d8×25
- 实测强调色：#487890×4
- 文字分带出现率：页眉 1.0 / 上部 0.96 / 中部 0.88 / 下部 0.96 / 底部 1.0

## 2. 画布与令牌
- 画布：1920×1080 / 30fps
- 底色：light `#f3eedf` → dark `#16282c`
- 墨色：`#27383a` / `#eef3ea`
- 唯一强调色：`#2f7f95`（暗底提亮 `#7cc7d6`）
- 辅助灰：`#7d847f` / `#9ca6a2`
- 字体：Noto Sans SC（标题 73–105px）· 正文 Noto Sans SC · HUD/微标 GeistMono；缺字回落 Noto Sans SC，全部为本地 OFL 字体

## 3. 版面
- 版心：左右 0.062 画布短边
- 标题块顶 0.150 高、开场大字顶 0.200 高
- 内容区 0.340–0.818 高，其下留字幕安全区

## 4. 装饰语言
- 底纹：mindmap
- 标题：plain；面板：paper；项目符号：dot
- 圆角：0.030 画布短边

## 5. 节奏
- 入场：pop / inout，元素间隔 0.22s
- 主题交替：light、dark，默认 light

## 6. 人物
- 默认样式：small；可用 card, small, none
- 竖卡 0.380×0.660（短边比），圆框直径 0.260
- 人物框几何与 `scripts/build_jianying_draft.py` 的 `FRAMES` 同源，`runtime.js` 与草稿不会错位
