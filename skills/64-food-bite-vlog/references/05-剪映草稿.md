# 剪映草稿与导出

## 两种交付

- `--export`：ffmpeg 一次出片。**画质跟着素材走**：iPhone 4K60 HLG HDR 素材输出 2160×3840、60 帧、HEVC Main10 HLG（4K60 约 60 Mbps）；SDR 素材 1080p 用 x264 CRF 17。不会擅自降分辨率、降帧率或转 SDR。HLG 成片里白字按 75% 信号画（约 203 nit 普通白），不会刺眼。
- `--draft`：生成剪映草稿目录 `<名字>_剪映草稿/`，素材以硬链接放进 `Resources/`（同盘不占双倍空间）。轨道：
  - 视频「主轨」：每段一个片段，入点出点、变速、原声音量、转场（剪映内置：叠化、闪白、闪黑、推近…）、滤镜（风格指定的剪映滤镜）都按剪辑单设好。
  - 文本「字幕」：字幕、时间戳、双语字幕是**原生文字**，可以直接在剪映里改字。
  - 视频「包装」：片头大字、商品标签、角标、片尾卡是透明 PNG 图片片段（剪映里可拖动、删除，但改字要回剪辑单重出）。
  - 音频「旁白」「配乐」：分轨，配乐带淡入淡出。
- `--preview`：540 宽快速预览，只用来看节奏。

## 草稿和成片的差异（已知）

- 成片里的颗粒、暗角、遮幅、白边相框、ffmpeg 调色，草稿里用「风格指定的剪映滤镜」近似，没有一一对应；需要时在剪映里手动加。
- 有转场的剪点，成片是「上一段尾巴叠进下一段开头」，剪映是转场跨在剪点两侧，视觉上几乎一样，时间轴上剪点位置一致。
- 剪映滤镜、转场、字体有的需要联网下载或会员；草稿没有在剪映里逐个打开核对过（`build-report.json` 里 `gui_verified: false`）。

## 放进剪映

先**完全退出剪映**，再运行：

```bash
python3 scripts/sync_draft.py <草稿目录> --root "$HOME/Movies/JianyingPro/User Data/Projects/com.lveditor.draft" --registry "$HOME/Movies/JianyingPro/User Data/Projects/com.lveditor.draft/root_meta_info.json"
```

不会覆盖已有草稿和首页索引（先备份 `root_meta_info.json`）。macOS 剪映的「导出」对话框没法自动点，**导出要用户自己在剪映里点**。
