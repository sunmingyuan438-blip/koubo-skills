# 黑板 · 知识讲解 · 风格规范

## 1. 参考片
`42_chalkboard`（210.0s，1920×1080，0 个切点，25 帧抽检）

- 底色分布：暗底均值 0.854（0.805–0.905）、亮底均值 0.0
- 主色板：#0a110f · #0e1613 · #111a17 · #151f1a · #18231e · #202923 · #303733 · #3d4640
- 最常见底色：#001818×17 / #000000×8
- 实测强调色：#a89048×4
- 文字分带出现率：页眉 1.0 / 上部 0.92 / 中部 0.44 / 下部 0.84 / 底部 0.92

## 2. 画布与令牌
- 画布：1920×1080 / 30fps
- 底色：light `#eef0e4` → dark `#1f3a30`
- 墨色：`#1d2b24` / `#eef0e4`
- 唯一强调色：`#2f6b52`（暗底提亮 `#f0d264`）
- 辅助灰：`#757e75` / `#9faba0`
- 字体：站酷快乐体 ZCOOL KuaiLe（标题 90–120px）· 正文 Noto Sans SC · HUD/微标 GeistMono；缺字回落 Noto Sans SC，全部为本地 OFL 字体

## 3. 版面
- 版心：左右 0.062 画布短边
- 标题块顶 0.150 高、开场大字顶 0.200 高
- 内容区 0.340–0.818 高，其下留字幕安全区

## 4. 装饰语言
- 底纹：chalk
- 标题：underline；面板：outline；项目符号：dash
- 圆角：0.004 画布短边

## 5. 节奏
- 入场：wipe / out3，元素间隔 0.2s
- 主题交替：dark、light，默认 dark

## 6. 人物
- 默认样式：card；可用 card, small, none
- 竖卡 0.400×0.700（短边比），圆框直径 0.215
- 人物框几何与 `scripts/build_jianying_draft.py` 的 `FRAMES` 同源，`runtime.js` 与草稿不会错位

## 7. 本风格专属记号
墨绿黑板 + 粉笔擦痕与木框 + 黄粉笔强调，老师板书的逐行书写感
