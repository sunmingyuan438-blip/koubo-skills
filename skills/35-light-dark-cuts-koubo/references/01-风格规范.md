# 明暗切 · 产品宣传 · 风格规范

## 1. 参考片
`35_light-dark-cuts`（57.0s，1920×1080，12 个切点，24 帧抽检）

- 底色分布：暗底均值 0.5（0.0–1.0）、亮底均值 0.358
- 主色板：#04040e · #0a091a · #100f24 · #19172d · #3a3579 · #483e4d · #563ee5 · #583dee
- 最常见底色：#000018×11 / #d8d8f0×9 / #4830d8×3
- 实测强调色：#4830d8×3 / #7860d8×2 / #7860f0×2
- 文字分带出现率：页眉 0.46 / 上部 0.62 / 中部 0.62 / 下部 0.79 / 底部 0.79

## 2. 画布与令牌
- 画布：1920×1080 / 30fps
- 底色：light `#f1f0f7` → dark `#120f24`
- 墨色：`#15122a` / `#f5f3ff`
- 唯一强调色：`#5a3cf0`（暗底提亮 `#f472b6`）
- 辅助灰：`#716f80` / `#9f9cac`
- 字体：Noto Sans SC（标题 88–120px）· 正文 Noto Sans SC · HUD/微标 GeistMono；缺字回落 Noto Sans SC，全部为本地 OFL 字体

## 3. 版面
- 版心：左右 0.062 画布短边
- 标题块顶 0.150 高、开场大字顶 0.200 高
- 内容区 0.340–0.818 高，其下留字幕安全区

## 4. 装饰语言
- 底纹：blocks
- 标题：tagged；面板：paper；项目符号：arrow
- 圆角：0.014 画布短边

## 5. 节奏
- 入场：wipe / out3，元素间隔 0.1s
- 主题交替：light、dark，默认 dark

## 6. 人物
- 默认样式：card；可用 card, small, none
- 竖卡 0.460×0.560（短边比），圆框直径 0.230
- 人物框几何与 `scripts/build_jianying_draft.py` 的 `FRAMES` 同源，`runtime.js` 与草稿不会错位

## 7. 本风格专属记号
亮/暗硬切 + 电光紫与粉 + 白卡片，一句一切的快节奏宣传
