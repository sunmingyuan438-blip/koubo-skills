# 现代编辑 · 横屏版 · 风格规范

## 1. 参考片
`07_modern-editorial-wide`（117.5s，1920×1080，3 个切点，28 帧抽检）

- 底色分布：暗底均值 0.415（0.007–0.96）、亮底均值 0.48
- 主色板：#000000 · #020202 · #040505 · #1151e6 · #141516 · #2e3642 · #433c37 · #4b6aa3
- 最常见底色：#f0f0f0×14 / #000000×14
- 实测强调色：#0048d8×9 / #4878d8×3 / #183060×1
- 文字分带出现率：页眉 1.0 / 上部 1.0 / 中部 0.82 / 下部 0.82 / 底部 0.21

## 2. 画布与令牌
- 画布：1920×1080 / 30fps
- 底色：light `#f6f5f2` → dark `#12100e`
- 墨色：`#16130f` / `#f6f4ee`
- 唯一强调色：`#1049d8`（暗底提亮 `#4878f0`）
- 辅助灰：`#726b62` / `#a9a29a`
- 字体：Noto Sans SC（标题 81–112px）· 正文 Noto Sans SC · HUD/微标 GeistMono；缺字回落 Noto Sans SC，全部为本地 OFL 字体

## 3. 版面
- 版心：左右 0.062 画布短边
- 标题块顶 0.150 高、开场大字顶 0.300 高
- 内容区 0.360–0.790 高，其下留字幕安全区

## 4. 装饰语言
- 底纹：none
- 标题：plain；面板：outline；项目符号：dash
- 圆角：0.004 画布短边

## 5. 节奏
- 入场：rise / out3，元素间隔 0.18s
- 主题交替：light、dark，默认 light

## 6. 人物
- 默认样式：small；可用 card, small, none
- 竖卡 0.467×0.644（短边比），圆框直径 0.220
- 人物框几何与 `scripts/build_jianying_draft.py` 的 `FRAMES` 同源，`runtime.js` 与草稿不会错位
