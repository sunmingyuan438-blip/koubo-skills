# 手绘卡通 · 横屏版 · 风格规范

## 1. 参考片
`14_hand-drawn-cartoon`（275.3s，1920×1080，2 个切点，29 帧抽检）

- 底色分布：暗底均值 0.063（0.04–0.265）、亮底均值 0.751
- 主色板：#181821 · #24273a · #494850 · #4c6fd6 · #6e7678 · #916e5f · #97a19f · #bdc1c2
- 最常见底色：#f0f0d8×28 / #f0d8d8×1
- 实测强调色：#f0c030×26 / #d89048×3 / #3060f0×2
- 文字分带出现率：页眉 1.0 / 上部 0.79 / 中部 0.66 / 下部 0.28 / 底部 0.97

## 2. 画布与令牌
- 画布：1920×1080 / 30fps
- 底色：light `#fdf6e3` → dark `#22201c`
- 墨色：`#22201c` / `#fdf6e3`
- 唯一强调色：`#e2762b`（暗底提亮 `#f59a4e`）
- 辅助灰：`#6f6a60` / `#a8a29a`
- 字体：站酷快乐体 ZCOOL KuaiLe（标题 90–120px）· 正文 Noto Sans SC · HUD/微标 GeistMono；缺字回落 Noto Sans SC，全部为本地 OFL 字体

## 3. 版面
- 版心：左右 0.062 画布短边
- 标题块顶 0.150 高、开场大字顶 0.300 高
- 内容区 0.360–0.810 高，其下留字幕安全区

## 4. 装饰语言
- 底纹：none
- 标题：underline；面板：paper；项目符号：check
- 圆角：0.030 画布短边

## 5. 节奏
- 入场：pop / inout，元素间隔 0.2s
- 主题交替：light、dark，默认 light

## 6. 人物
- 默认样式：card；可用 card, small, none
- 竖卡 0.441×0.707（短边比），圆框直径 0.240
- 人物框几何与 `scripts/build_jianying_draft.py` 的 `FRAMES` 同源，`runtime.js` 与草稿不会错位

## 7. 本风格专属记号
米黄纸 + 手绘描边 + 橙色重点
