# 深空多维舞台 · 竖屏版 · 风格规范

## 1. 参考片
`09_dark-dimensional-stage`（122.4s，1080×1920，7 个切点，28 帧抽检）

- 底色分布：暗底均值 0.603（0.0–0.973）、亮底均值 0.229
- 主色板：#020202 · #04070d · #090f1c · #1352e5 · #191f32 · #284d9c · #52575b · #655d57
- 最常见底色：#000000×18 / #f0f0f0×6 / #0048d8×2
- 实测强调色：#0048d8×6 / #604830×2 / #4878f0×2
- 文字分带出现率：页眉 0.93 / 上部 0.86 / 中部 0.75 / 下部 0.5 / 底部 0.36

## 2. 画布与令牌
- 画布：1080×1920 / 30fps
- 底色：light `#eef1f6` → dark `#04060d`
- 墨色：`#0c1018` / `#e9eefb`
- 唯一强调色：`#3b6cf0`（暗底提亮 `#6f95ff`）
- 辅助灰：`#5f6878` / `#8e99ad`
- 字体：Noto Sans SC（标题 69–99px）· 正文 Noto Sans SC · HUD/微标 GeistMono；缺字回落 Noto Sans SC，全部为本地 OFL 字体

## 3. 版面
- 版心：左右 0.068 画布短边
- 标题块顶 0.140 高、开场大字顶 0.250 高
- 内容区 0.300–0.780 高，其下留字幕安全区

## 4. 装饰语言
- 底纹：gradient
- 标题：tagged；面板：glass；项目符号：dot
- 圆角：0.016 画布短边

## 5. 节奏
- 入场：settle / inout，元素间隔 0.16s
- 主题交替：dark、light，默认 dark

## 6. 人物
- 默认样式：small；可用 card, small, none
- 竖卡 0.243×0.340（短边比），圆框直径 0.270
- 人物框几何与 `scripts/build_jianying_draft.py` 的 `FRAMES` 同源，`runtime.js` 与草稿不会错位

## 7. 本风格专属记号
深海蓝底 + 玻璃面板 + 多屏分栏
