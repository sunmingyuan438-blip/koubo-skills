# 科技 · 换机还是再等等 · 风格规范

## 1. 参考片
`23_industry-tech`（102.6s，1080×1920，1 个切点，26 帧抽检）

- 底色分布：暗底均值 0.868（0.727–0.97）、亮底均值 0.032
- 主色板：#0b0f15 · #13171f · #191e29 · #1d2638 · #30384b · #495a7e · #5686de · #645a51
- 最常见底色：#000000×26
- 实测强调色：#3078f0×7 / #183060×3 / #f0a818×2
- 文字分带出现率：页眉 1.0 / 上部 0.92 / 中部 0.92 / 下部 0.96 / 底部 1.0

## 2. 画布与令牌
- 画布：1080×1920 / 30fps
- 底色：light `#f2f2f2` → dark `#050607`
- 墨色：`#0a0c0e` / `#f7f9fa`
- 唯一强调色：`#4a90e0`（暗底提亮 `#5ea4f5`）
- 辅助灰：`#6d7378` / `#8d969c`
- 字体：Noto Sans SC（标题 118–156px）· 正文 Noto Sans SC · HUD/微标 GeistMono；缺字回落 Noto Sans SC，全部为本地 OFL 字体

## 3. 版面
- 版心：左右 0.068 画布短边
- 标题块顶 0.140 高、开场大字顶 0.250 高
- 内容区 0.300–0.690 高，其下留字幕安全区

## 4. 装饰语言
- 底纹：hairline
- 标题：plain；面板：outline；项目符号：dash
- 圆角：0.004 画布短边

## 5. 节奏
- 入场：pop / out3，元素间隔 0.1s
- 主题交替：dark、light，默认 dark

## 6. 人物
- 默认样式：small；可用 card, small, none
- 竖卡 0.228×0.319（短边比），圆框直径 0.228
- 人物框几何与 `scripts/build_jianying_draft.py` 的 `FRAMES` 同源，`runtime.js` 与草稿不会错位

## 7. 本风格专属记号
科技类：近黑 + 电光蓝，对比先行、参数数字驱动
