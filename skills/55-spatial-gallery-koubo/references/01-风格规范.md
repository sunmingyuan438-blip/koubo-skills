# 空间画廊 · 照片回忆 · 风格规范

## 1. 参考片
`55_spatial-gallery`（14.0s，1920×1080，0 个切点，14 帧抽检）

- 底色分布：暗底均值 0.85（0.537–1.0）、亮底均值 0.022
- 主色板：#0b0a08 · #171512 · #27241d · #35415a · #3e3d35 · #483f21 · #545c71 · #676833
- 最常见底色：#000000×13 / #181800×1
- 实测强调色：#484818×4 / #606018×3 / #003078×2
- 文字分带出现率：页眉 0.64 / 上部 0.0 / 中部 0.57 / 下部 0.71 / 底部 0.21

## 2. 画布与令牌
- 画布：1920×1080 / 30fps
- 底色：light `#efeae0` → dark `#171512`
- 墨色：`#1c1915` / `#f2ede3`
- 唯一强调色：`#7a5a2c`（暗底提亮 `#e8d9b4`）
- 辅助灰：`#75716a` / `#9f9b94`
- 字体：Noto Sans SC（标题 84–114px）· 正文 Noto Sans SC · HUD/微标 GeistMono；缺字回落 Noto Sans SC，全部为本地 OFL 字体

## 3. 版面
- 版心：左右 0.062 画布短边
- 标题块顶 0.150 高、开场大字顶 0.200 高
- 内容区 0.340–0.818 高，其下留字幕安全区

## 4. 装饰语言
- 底纹：gallery
- 标题：plain；面板：paper；项目符号：dash
- 圆角：0.002 画布短边

## 5. 节奏
- 入场：flip / inout，元素间隔 0.2s
- 主题交替：dark、light，默认 dark

## 6. 人物
- 默认样式：card；可用 card, small, none
- 竖卡 0.460×0.560（短边比），圆框直径 0.230
- 人物框几何与 `scripts/build_jianying_draft.py` 的 `FRAMES` 同源，`runtime.js` 与草稿不会错位

## 7. 本风格专属记号
暗色展厅 + 地面透视线 + 白边相纸卡片翻入，年份—地点的回忆走廊
