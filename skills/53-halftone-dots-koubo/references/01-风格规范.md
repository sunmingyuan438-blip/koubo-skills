# 半调网点 · 人像标题 · 风格规范

## 1. 参考片
`53_halftone-dots`（13.0s，1920×1080，0 个切点，13 帧抽检）

- 底色分布：暗底均值 0.8（0.027–1.0）、亮底均值 0.039
- 主色板：#040304 · #0f080a · #1d1413 · #2b1d1a · #3c2722 · #51332a · #684032 · #7e4b39
- 最常见底色：#000000×10 / #a89078×2 / #a84830×1
- 实测强调色：#604830×2 / #f0c060×2 / #183048×2
- 文字分带出现率：页眉 0.31 / 上部 0.0 / 中部 0.08 / 下部 0.08 / 底部 0.0

## 2. 画布与令牌
- 画布：1920×1080 / 30fps
- 底色：light `#f4efe8` → dark `#0b0b0d`
- 墨色：`#17120e` / `#f6efe6`
- 唯一强调色：`#b84a24`（暗底提亮 `#f3c58a`）
- 辅助灰：`#746f6a` / `#9d9894`
- 字体：Noto Sans SC（标题 84–114px）· 正文 Noto Sans SC · HUD/微标 GeistMono；缺字回落 Noto Sans SC，全部为本地 OFL 字体

## 3. 版面
- 版心：左右 0.062 画布短边
- 标题块顶 0.150 高、开场大字顶 0.200 高
- 内容区 0.340–0.818 高，其下留字幕安全区

## 4. 装饰语言
- 底纹：halftone
- 标题：plain；面板：outline；项目符号：dash
- 圆角：0.000 画布短边

## 5. 节奏
- 入场：rise / inout，元素间隔 0.2s
- 主题交替：dark、light，默认 dark

## 6. 人物
- 默认样式：card；可用 card, small, none
- 竖卡 0.400×0.700（短边比），圆框直径 0.215
- 人物框几何与 `scripts/build_jianying_draft.py` 的 `FRAMES` 同源，`runtime.js` 与草稿不会错位

## 7. 本风格专属记号
近黑底 + 从角落涌入的半调网点（杏色/青色）+ 细线框，人物是主角
