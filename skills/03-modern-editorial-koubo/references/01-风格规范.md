# 现代编辑 · 竖屏版 · 风格规范

## 1. 参考片
`03_modern-editorial`（117.5s，1080×1920，3 个切点，28 帧抽检）

- 底色分布：暗底均值 0.458（0.006–0.97）、亮底均值 0.5
- 主色板：#000000 · #020202 · #040405 · #0a0d10 · #1252e6 · #18191a · #2d2e32 · #2d62dd
- 最常见底色：#f0f0f0×14 / #000000×14
- 实测强调色：#0048d8×8 / #183060×1
- 文字分带出现率：页眉 0.96 / 上部 0.93 / 中部 0.86 / 下部 0.57 / 底部 0.04

## 2. 画布与令牌
- 画布：1080×1920 / 30fps
- 底色：light `#f6f5f2` → dark `#12100e`
- 墨色：`#16130f` / `#f6f4ee`
- 唯一强调色：`#1049d8`（暗底提亮 `#4878f0`）
- 辅助灰：`#726b62` / `#a9a29a`
- 字体：Noto Sans SC（标题 81–112px）· 正文 Noto Sans SC · HUD/微标 GeistMono；缺字回落 Noto Sans SC，全部为本地 OFL 字体

## 3. 版面
- 版心：左右 0.068 画布短边
- 标题块顶 0.255 高、开场大字顶 0.270 高
- 内容区 0.360–0.700 高，其下留字幕安全区

## 4. 装饰语言
- 底纹：none
- 标题：plain；面板：outline；项目符号：dash
- 圆角：0.004 画布短边

## 5. 节奏
- 入场：rise / out3，元素间隔 0.18s
- 主题交替：light、dark，默认 light

## 6. 人物
- 默认样式：small；可用 card, small, none
- 竖卡 0.174×0.239（短边比），圆框直径 0.206
- 人物框几何与 `scripts/build_jianying_draft.py` 的 `FRAMES` 同源，`runtime.js` 与草稿不会错位

## 7. 本风格专属记号
