# 等距系统 · 知识讲解 · 风格规范

## 1. 参考片
`49_isometric-systems`（195.7s，1920×1080，0 个切点，24 帧抽检）

- 底色分布：暗底均值 0.0（0.0–0.002）、亮底均值 0.884
- 主色板：#404b53 · #666f77 · #828f95 · #8caebb · #a3c0d0 · #acbfca · #c4d0d3 · #c5a488
- 最常见底色：#d8d8d8×24
- 实测强调色：#d8a860×3 / #48a8c0×1 / #d89078×1
- 文字分带出现率：页眉 1.0 / 上部 0.62 / 中部 0.54 / 下部 0.62 / 底部 0.88

## 2. 画布与令牌
- 画布：1920×1080 / 30fps
- 底色：light `#e9eef1` → dark `#14222a`
- 墨色：`#24313a` / `#e6f0f2`
- 唯一强调色：`#1f8f8f`（暗底提亮 `#6fd6d0`）
- 辅助灰：`#778087` / `#96a2a6`
- 字体：Noto Sans SC（标题 69–99px）· 正文 Noto Sans SC · HUD/微标 GeistMono；缺字回落 Noto Sans SC，全部为本地 OFL 字体

## 3. 版面
- 版心：左右 0.062 画布短边
- 标题块顶 0.150 高、开场大字顶 0.200 高
- 内容区 0.340–0.818 高，其下留字幕安全区

## 4. 装饰语言
- 底纹：iso
- 标题：tagged；面板：paper；项目符号：check
- 圆角：0.010 画布短边

## 5. 节奏
- 入场：settle / inout，元素间隔 0.16s
- 主题交替：light、dark，默认 light

## 6. 人物
- 默认样式：card；可用 card, small, none
- 竖卡 0.400×0.700（短边比），圆框直径 0.215
- 人物框几何与 `scripts/build_jianying_draft.py` 的 `FRAMES` 同源，`runtime.js` 与草稿不会错位

## 7. 本风格专属记号
冷灰蓝底 + 等距网格与小方块 + 青绿/橙的冷暖对照，系统怎么运转
