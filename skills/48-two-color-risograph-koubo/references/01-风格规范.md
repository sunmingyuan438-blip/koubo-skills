# 双色孔版 · 知识讲解 · 风格规范

## 1. 参考片
`48_two-color-risograph`（194.8s，1920×1080，0 个切点，25 帧抽检）

- 底色分布：暗底均值 0.011（0.0–0.042）、亮底均值 0.887
- 主色板：#341f60 · #473369 · #52678e · #735e86 · #7886a1 · #949eb0 · #a08ca9 · #aeb7c4
- 最常见底色：#f0d8d8×18 / #d8d8d8×7
- 实测强调色：#301860×10 / #481860×5 / #486090×5
- 文字分带出现率：页眉 1.0 / 上部 0.92 / 中部 0.64 / 下部 0.52 / 底部 0.8

## 2. 画布与令牌
- 画布：1920×1080 / 30fps
- 底色：light `#f2eee4` → dark `#201e52`
- 墨色：`#2d2a6e` / `#f2eee4`
- 唯一强调色：`#d92f85`（暗底提亮 `#ff6fb5`）
- 辅助灰：`#807ca0` / `#a29fad`
- 字体：Noto Sans SC（标题 99–138px）· 正文 Noto Sans SC · HUD/微标 GeistMono；缺字回落 Noto Sans SC，全部为本地 OFL 字体

## 3. 版面
- 版心：左右 0.062 画布短边
- 标题块顶 0.150 高、开场大字顶 0.200 高
- 内容区 0.340–0.818 高，其下留字幕安全区

## 4. 装饰语言
- 底纹：riso
- 标题：plain；面板：hard；项目符号：dot
- 圆角：0.004 画布短边

## 5. 节奏
- 入场：pop / out3，元素间隔 0.14s
- 主题交替：light、dark，默认 light

## 6. 人物
- 默认样式：card；可用 card, small, none
- 竖卡 0.420×0.520（短边比），圆框直径 0.240
- 人物框几何与 `scripts/build_jianying_draft.py` 的 `FRAMES` 同源，`runtime.js` 与草稿不会错位

## 7. 本风格专属记号
米白纸 + 藏青与玫红两套网点叠印 + 套准十字，粗标题、硬投影
