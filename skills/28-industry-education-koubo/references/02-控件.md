# 教培 · 三套方案 · 控件

8 个控件，字段超限或取值不合法时 `build` 直接报错，不缩字不截断。

| 控件 | 用途 |
| --- | --- |
| `opener` | 开场：kicker + 两行大字 + 一句副标 |
| `chapter` | 章节页：编号 + 栏目名 + 一行说明 |
| `compare` | 双栏对比：左右各 3–4 条 |
| `grid` | 宫格：2×2 / 3×3，卡片带中英文微标 |
| `steps` | 步骤卡：3–4 张卡，编号 + 一行说明 |
| `banner` | 结论横幅：标题 + 标签胶囊组（最后一个强调色）+ 强调色实心横幅（结论标签 + 一句结论） |
| `reveal` | 巨字揭晓：两行问题 + 白色答案卡 + 溢出卡片右侧的强调色巨字 |
| `outro` | 结尾：一句话结论 + 下划线 |

## 每控件的字段与上限
| 控件 | 字段（上限） |
| --- | --- |
| opener | kicker 20 · line1 9 · line2 11 · sub 24 · foot 24 |
| statement | kicker 20 · text 44 · source 18 |
| chapter | no 5 · name 12 · sub 18 · foot 24 |
| list | kicker 20 · title 11 · items 6×20 |
| steps | kicker 20 · title 11 · items 4×18 |
| compare | kicker 20 · title 11 · leftLabel 8 · rightLabel 8 · left 4×14 · right 4×14 |
| grid | kicker 20 · title 11 · items 9×{zh 12, en 14} |
| counter | kicker 20 · title 11 · label 12 · value 6 · unit 4 · note 28 |
| quote | kicker 20 · text 44 · source 18 |
| outro | kicker 20 · line1 12 · line2 12 · note 18 |
| imageSlot | kicker 20 · title 11 · caption 24 · src（png/jpg/webp，文件必须存在）· ratio（16:9 / 4:3 / 1:1 / 3:4 / 9:16） |
| bars | kicker 20 · title 11 · items 6×{label 8, value 6（必须是数字）} · unit 4 · note 28 · focus（1 起的整数） |
| split | kicker 20 · title 9 · items 3×16（镜头人物强制为 split） |
| banner | kicker 20 · title 11 · tags 4×6 · label 8 · line 22 |
| reveal | q1 9 · q2 9 · label 8 · line 14 · sub 16 · word 5 |

## 用法要点
- `*词*` → 强调色（`b` 标签取 `--accent`）
- 每个控件都可带 `foot`（页脚微标，≤24 字）
- `theme` 取 light, dark；`presenter` 取 card, small, none
