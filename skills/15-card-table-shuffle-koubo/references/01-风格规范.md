# 卡牌桌 · 横屏版 · 风格规范

## 1. 参考片
`15_card-table-shuffle`（200.7s，1920×1080，1 个切点，28 帧抽检）

- 底色分布：暗底均值 0.069（0.0–0.775）、亮底均值 0.734
- 主色板：#09090a · #212120 · #423e3c · #5387f0 · #6c5b56 · #85a6f1 · #898786 · #a47a67
- 最常见底色：#d8d8d8×27 / #000000×1
- 实测强调色：#4878f0×6 / #6090f0×5 / #3078f0×3
- 文字分带出现率：页眉 1.0 / 上部 0.71 / 中部 0.79 / 下部 0.54 / 底部 0.86

## 2. 画布与令牌
- 画布：1920×1080 / 30fps
- 底色：light `#f6f3ea` → dark `#14120f`
- 墨色：`#141216` / `#f3eee6`
- 唯一强调色：`#4878f0`（暗底提亮 `#6f95ff`）
- 辅助灰：`#6b6670` / `#9d97a2`
- 字体：Noto Sans SC（标题 84–114px）· 正文 Noto Sans SC · HUD/微标 GeistMono；缺字回落 Noto Sans SC，全部为本地 OFL 字体

## 3. 版面
- 版心：左右 0.062 画布短边
- 标题块顶 0.150 高、开场大字顶 0.300 高
- 内容区 0.360–0.763 高，其下留字幕安全区

## 4. 装饰语言
- 底纹：none
- 标题：plain；面板：paper；项目符号：number
- 圆角：0.020 画布短边

## 5. 节奏
- 入场：rise / inout，元素间隔 0.18s
- 主题交替：dark、light，默认 light

## 6. 人物
- 默认样式：card；可用 card, small, split, none
- 竖卡 0.589×0.726（短边比），圆框直径 0.240
- 人物框几何与 `scripts/build_jianying_draft.py` 的 `FRAMES` 同源，`runtime.js` 与草稿不会错位

## 7. 本风格专属记号
浅色牌桌 + 卡牌叠放节奏
